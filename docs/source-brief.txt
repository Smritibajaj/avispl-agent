Three queries to show Nancy:

Each one is written the way a customer would actually type it, and each one exercises a different thing the tool does.
1. “We have about 40 meeting rooms across three offices, all on Microsoft Teams. Which AVI-SPL reference designs should we standardise on for small, medium and large rooms, and what should we think about for remote participants?”

This pulls the reference designs, the standardisation eBook and the meeting equity guidance into one answer with citations. It shows synthesis across documents, which is the thing a site search cannot do.
2. “What do we need in place to use Copilot and Microsoft Places in our Teams Rooms, and has AVI-SPL done this for an organisation like ours?”

This pulls the Microsoft practice pages, the smart workplace eBook and the IDRC case study. It shows that the tool surfaces proof, not just product pages, and that it carries the licensing disclosure Nancy fought to get into the eBook.
3. “Once the rooms are installed, how do we monitor them, and what happens if a room fails ten minutes before a board meeting?”

This pulls Symphony, support and maintenance, managed services and the Bernalillo County case study. It shows the tool covers the part of the journey where customers usually go quiet, and it sets up the managed services upsell AVI-SPL’s sales team wants.
